# CineMatrix Sovereign Studio

A multi-agent cinematic intelligence system built on a sovereign zero-trust architecture.

## Overview

CineMatrix generates high-concept film pitches, screenplay structures, cinematography plans, and financial models using coordinated autonomous agents. Perfect for Devpost submissions, film festival pitches, and creative development.

**System Status:** Stable | **Security Model:** Sovereign Zero-Trust | **Mode:** Production Ready

## Features

- ✨ **Multi-Agent Swarm Pipeline** — Coordinated Executive Producer, Screenwriter, Cinematographer, and Financial Analyst agents
- 🛡️ **Zero-Trust Reentrancy Shield** — Prevents recursive paradox loops and ensures deterministic outputs
- 🎬 **Cinematic Domain Specialization** — Each agent leverages deep expertise in their domain
- ⚙️ **Stable, Non-Recursive Architecture** — Guarantees predictable, reproducible results
- 📋 **Unified Sovereign Dossier** — Complete cinematic package ready for production greenlight

## Quick Start

### 1. Copy the Swarm Prompt
Open `cine_matrix_prompt.txt` and copy its full contents.

### 2. Use in Your AI Studio
Paste into Google AI Studio, Claude, or your preferred LLM platform as a system prompt.

### 3. Provide Your Premise
Input a high-concept cinematic premise (1-3 sentences):

```
PREMISE: "In submerged Venice, 2088, a rogue neural protocol begins 
altering reality through cinematic logic. A small creative team must 
contain the phenomenon before it spreads."

EXECUTE: INITIATE SOVEREIGN SWARM SYNTHESIS — MODE: STABLE
```

### 4. Receive Your Dossier
The system outputs a complete Sovereign Dossier with:
- Logline
- 3-Act Structure
- Character Matrix
- Shot Bible
- Color Palette
- Budget & ROI
- Final Verdict

## System Architecture

### Agents

1. **Executive Producer** — Market positioning, competitive analysis, audience targeting, franchise potential
2. **Screenwriter** — 3-act structure, character development, dialogue, thematic resonance
3. **Cinematographer** — Visual language, color palette, shot design, atmospheric control
4. **Financial Analyst** — Budget breakdowns, ROI projections, financing strategy, profit modeling

### Zero-Trust Reentrancy Shield

Ensures system stability through:
- Input/output validation
- Contradiction detection
- Recursion prevention
- Logical consistency checking
- One-allowed-per-agent contradiction resolution

### Execution Protocol

```
Premise Input
    ↓
Swarm Root Initialization
    ↓
Parallel Agent Analysis
    ↓
Zero-Trust Validation
    ↓
Contradiction Resolution (if needed)
    ↓
Unified Synthesis
    ↓
Final Stability Checkpoint
    ↓
Sovereign Dossier Output
```

## Design Principles

- **Sovereignty** — Complete autonomy; no external overrides
- **Stability** — Deterministic outputs; no chaotic behavior
- **Transparency** — All decisions logged and explainable
- **Specialization** — Deep domain expertise per agent
- **Coordination** — Structured synthesis, not conflict

## Troubleshooting

**Getting generic output?**
→ Make your premise more specific and unusual

**Budget seems unrealistic?**
→ Cross-reference with comparable films in genre

**Character arcs feel flat?**
→ Refine premise to include deeper character conflict

**Recursive output detected?**
→ Ensure "MODE: STABLE" and "ZERO-TRUST: ACTIVE" in prompt

See `demo_script.md` for extended troubleshooting guide.
