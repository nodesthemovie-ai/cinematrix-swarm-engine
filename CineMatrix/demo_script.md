# CineMatrix Demo Script

## Quick Start Guide

### Step 1: Prepare Your Premise
Define a high-concept cinematic premise in 1-2 sentences.

**Example:**
> "In submerged Venice, 2088, a rogue neural protocol begins altering reality through cinematic logic. A small creative team must contain the phenomenon before it spreads."

### Step 2: Load the Swarm Prompt
Use the contents of `cine_matrix_prompt.txt` as your system prompt in an AI platform:
- **Google AI Studio** (recommended)
- Claude (Anthropic)
- OpenAI GPT-4
- Any LLM with multi-agent capability

### Step 3: Input Your Premise
Provide your premise to the system:

```
PREMISE: [Your high-concept premise here]
EXECUTE: INITIATE SOVEREIGN SWARM SYNTHESIS — MODE: STABLE
```

### Step 4: Receive Unified Dossier
The system will output a comprehensive Sovereign Dossier containing:

- **Logline** — One-line pitch
- **3-Act Structure** — Full story breakdown
- **Character Matrix** — Protagonist, antagonist, supporting cast
- **Shot Bible** — Visual style & cinematography guide
- **Color Palette** — Mood board & atmospheric colors
- **Budget & ROI** — Production costs & revenue projections
- **Final Verdict** — Viability & greenlight recommendation

## Tips for Best Results

### Premise Crafting
✓ Be specific about setting, stakes, and central conflict
✓ Include sci-fi/speculative element for cinematic potential
✓ Keep it to 2-3 sentences maximum
✓ Avoid existing franchise references

### System Configuration
✓ Use "MODE: STABLE" for consistent, reproducible outputs
✓ Include "SOVEREIGN_ONLY" for independent analysis
✓ Ensure zero-trust validation is active
✓ Allow full swarm synthesis before reviewing output

### Output Review
✓ Check for recursion paradoxes (Zero-Trust Shield should catch these)
✓ Verify character arcs are psychologically sound
✓ Validate budget against comparable films
✓ Assess thematic coherence across all domains

### Iteration
✓ Refine premise based on Initial output
✓ Run multiple premises to compare options
✓ Combine best elements from different dossiers
✓ Prepare final output for production pitches

## Advanced Usage

### Running Multiple Premises
Generate multiple dossiers in sequence and compare:

```
COMPARE MODE:
Premise A: [First premise]
Premise B: [Second premise]
Premise C: [Third premise]
GENERATE: All three in parallel
COMPARE: Viability, market fit, production feasibility
```

### Refinement Cycles
Iterate on a single premise with feedback:

```
ITERATION 1: Initial dossier
FEEDBACK: [Notes on what to adjust]
ITERATION 2: Refined dossier with adjustments
FEEDBACK: [More refinements]
ITERATION 3: Final polished dossier
```

### Pitch Deck Export
Use the dossier to generate Devpost submission:
1. Copy logline to title/tagline
2. Use character matrix for casting notes
3. Extract budget/ROI for financial section
4. Use shot bible for visual reference deck
5. Include final verdict as recommendation

## Troubleshooting

| Issue | Solution |
|---|---|
| Recursive output | Ensure "ZERO-TRUST: ACTIVE" and "MODE: STABLE" |
| Missing character details | Re-run with longer character-focused prompt |
| Inconsistent visual style | Verify cinematographer output against shot bible |
| Budget seems low/high | Cross-reference with comparable films |
| Output feels generic | Refine premise with more unique specific details |
