## How to Update

### From v1.0.0 to v1.1.0
```bash
git fetch origin
git checkout main
git pull origin main
git describe --tags  # Should show v1.1.0
```

### Install Latest Release
```bash
# Clone repository at latest tag
git clone --branch v1.1.0 https://github.com/nodesthemovie-ai/cinematrix-swarm-engine.git

# Or fetch specific release files
cd cinematrix-swarm-engine
git checkout v1.1.0
```
